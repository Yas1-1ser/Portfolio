## 💻 Local Development

The project uses a clean "Content-as-Data" architecture. All content is stored in `data.js` and rendered dynamically by `script.js`.

To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Yas1-1ser/Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Portfolio
   ```
3. Open `portfo.html` in your web browser, or serve it using a local development server:
   ```bash
   npx serve .
   ```
   *Note: Using a local web server is recommended for full feature support.*
